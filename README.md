# 방또샵 (BangTToShop)

포토샵처럼 레이어로 작업하는 무료 이미지 편집 프로그램입니다.

**100% 무료 · 가정용·상업용 모두 사용 가능 · 광고 없음 · 정보 수집 없음**

## 다운로드

오른쪽 **Releases**에서 최신 버전을 받으세요.

| 운영체제 | 파일 |
|---|---|
| Windows 10 / 11 (64비트) | `BangTToShop-Setup.exe` |
| macOS (Apple 실리콘) | `BangTToShop-arm64.dmg` |
| macOS (Intel) | `BangTToShop-x64.dmg` |

- 코드 서명이 없어서 Windows에서 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. **[추가 정보] → [실행]**을 누르세요.
- macOS에서 "확인되지 않은 개발자" 경고가 뜨면 응용 프로그램 폴더의 방또샵을 **우클릭 → [열기]**로 한 번 실행하세요.

## 특징

- PSD 파일을 레이어 그대로 열고 저장
- 레이어, 마스크, 레이어 스타일, 조정, 필터
- 선택·자르기·변형·브러시·텍스트·도형 등 편집 도구
- 사진, 디자인 파일, 카메라 RAW까지 폭넓은 형식 지원
- 모든 작업을 내 컴퓨터에서 처리

## 지원 형식

- 열기: PSD, PNG, JPG, WebP, GIF, BMP, AVIF, SVG, ICO, TIFF, TGA, DDS, PCX, PBM/PGM/PPM, HEIC/HEIF, PDF, AI
- 카메라 RAW: DNG, CR2, CR3, NEF, ARW, RW2, RAF, ORF, PEF, SRW 등
- 저장·내보내기: PSD, PNG, JPG, WebP, TIFF, TGA, BMP, GIF, ICO, PDF, SVG

## 라이선스

방또샵은 개인·가정·기업·학교 등 어디서든 무료로 사용할 수 있습니다.
원본 그대로 무료 재배포는 가능하지만 판매나 변조 배포는 할 수 없습니다. 전문은 [LICENSE.txt](LICENSE.txt)를 보세요.
